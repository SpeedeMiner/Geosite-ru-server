# Синхронизация GeoSite RU Server v11.19

- Источник: [GeoSite RU Light v11.19](https://github.com/SpeedeMiner/Geosite-ru-light/releases/tag/v11.19), коммит `ec6214b628162011ea1b4ebaf454cf0f6ae795d9`.
- SHA-256 исходного `geosite_RU.dat`: `fea7efa5c855ead11d2e8dd867f41d3b395afddba10013d0613e0c592ea7ca9f`.
- В Light добавлены 83 правила `full:` для публичных IP-чекеров. В сравнении с плавающим релизом Light: `RU` +83, удалений нет, остальные 17 категорий без изменений.
- Серверная сборка выбирает наибольший стабильный номерной релиз Light и извлекает только `RU`; проверяет SHA-256 источника и не допускает потери покрытия относительно опубликованного Server DAT.

Эта запись фиксирует исходные данные синхронизации. Итоговые контрольные суммы серверных артефактов публикуются в одноимённом релизе Server.
